The guides show one feature at a time. The repository's
[`examples/`](https://github.com/monarcode/effetch/tree/main/examples)
folder has programs that use them together for a real task, against free
public APIs that need no key or account. Each one prints what it did, so
you can run it, then read its code.

## Run an example

Clone the repository, run `pnpm install`, then name the example:

```sh
pnpm example github
```

This builds the package if its source has changed, then runs the
example's `main.ts`. It needs Node.js 22.18 or later, which runs TypeScript
files as they are. `pnpm example store-react` starts that app's dev server
instead.

The public APIs can be slow, rate-limited or down. The examples' tests
don't call them: each one runs against a fake backend made with
`FetchTest`, offline. Run them with `pnpm vitest run examples`.

The examples on the `main` branch can be ahead of the latest release. To
read them as they were at your version, switch GitHub's branch menu to that
release's tag, such as `v0.1.0`.

## The examples

Read them in this order, since each builds on the ones before it:

- [`github/`](https://github.com/monarcode/effetch/tree/main/examples/github):
  shows a repository and its open issues, with a client as a service,
  endpoints, errors of your own for a `404` and a rate limit, paging by the
  `Link` header, `Retry-After` and a plugin of your own.
- [`sign-in/`](https://github.com/monarcode/effetch/tree/main/examples/sign-in):
  signs in, renews the access token with `bearer`'s `refresh` when the
  server refuses it, and signs out. The session is an Effect service.
- [`live/`](https://github.com/monarcode/effetch/tree/main/examples/live):
  prints Wikipedia's edits as Server-Sent Events, and the moves of Lichess
  TV's game as newline-delimited JSON, with a client for each backend.
- [`upload/`](https://github.com/monarcode/effetch/tree/main/examples/upload):
  uploads a file and form fields as a multipart body, after checking the
  file's size.
- [`bff/`](https://github.com/monarcode/effetch/tree/main/examples/bff): a
  server calls a backend, and a browser client calls the server over Effect
  RPC. `Fetch.errorCodec` sends the call's errors across, and the example
  prints what crossed.
- [`store/`](https://github.com/monarcode/effetch/tree/main/examples/store):
  a shop app in feature modules, with a workflow that spans two of them, a
  `ManagedRuntime` for the UI, and the workflow's tests.
- [`store-react/`](https://github.com/monarcode/effetch/tree/main/examples/store-react):
  the same modules behind a React app routed with TanStack Router. Its
  loaders run their calls with the store's runtime and the route's abort
  signal, so leaving a page cancels its request. A missing product is the
  router's not-found page, and the other errors reach the route's error
  component, typed.

The examples'
[README](https://github.com/monarcode/effetch/blob/main/examples/README.md)
lists the APIs each one calls, and explains how `store/` and
`store-react/` are laid out.

With a client in hand, every call is one method: you pass the path and an
object of options, and get an Effect back.

## Pick a method

A client has a method for each HTTP method:

- `get`, `head` and `options` send no body.
- `post`, `put`, `patch` and `del` can send one. It's `del` because `delete`
  is a reserved word.
